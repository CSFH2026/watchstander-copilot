1. [step: WH-12890517-01] Open or create an HTML file in Visual Studio Code. requires: none
2. [step: WH-12890517-02] Click the Extensions button on the left side. requires: 01
3. [step: WH-12890517-03] Search for "HTML Preview" and install it. requires: 02
4. [step: WH-12890517-04] Click the tab for your HTML file at the top. requires: 03
5. [step: WH-12890517-05] Click the icon that resembles a split-screen with a magnifying glass at the top. requires: 04
