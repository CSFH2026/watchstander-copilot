1. [step: WH-1375465-01] Type your code in Notepad. requires: none
2. [step: WH-1375465-02] Go to File > Save As. requires: 01
3. [step: WH-1375465-03] Select All Files from the "Save as type" menu. requires: 02
4. [step: WH-1375465-04] Name the file "filename.exe" and click Save. requires: 03
5. [step: WH-1375465-05] Open iexpress. requires: 04
6. [step: WH-1375465-06] Select "Create a new Self Extraction Directive file" and click Next. requires: 05
7. [step: WH-1375465-07] Select Extract files only and click Next. requires: 06
8. [step: WH-1375465-08] Name and configure the file. requires: 07
9. [step: WH-1375465-09] Add the .exe file you created. requires: 08
10. [step: WH-1375465-10] Follow the on-screen instructions to create the package. requires: 09
