1. [step: WH-11165210-01] Open MySQL Workbench. requires: none
2. [step: WH-11165210-02] Double-click a model under "MySQL Connections.". requires: 01
3. [step: WH-11165210-03] Click File on the top-left. requires: 02
4. [step: WH-11165210-04] Click Open SQL Script. requires: 03
5. [step: WH-11165210-05] Select your SQL file. requires: 04
6. [step: WH-11165210-06] Click Open. requires: 05
