1. [step: WH-11212531-01] Install and update Java on your computer. requires: none
2. [step: WH-11212531-02] Open a Terminal window. requires: 01
3. [step: WH-11212531-03] Run "sudo useradd -r -m -U -d /opt/tomcat -s /bin/false tomcat.". requires: 02
4. [step: WH-11212531-04] Open the Tomcat website, and click a version on the left menu. requires: 03
5. [step: WH-11212531-05] Right-click tar.gz under "Core," and click Copy Link Address. requires: 04
6. [step: WH-11212531-06] Run "wget " with the copied link. requires: 05
7. [step: WH-11212531-07] Run "sudo tar xf /tmp/apache-tomcat-9*.tar.gz -C /opt/tomcat.". requires: 06
8. [step: WH-11212531-08] Run "sudo nano /etc/systemd/system/tomcat.service.". requires: 07
9. [step: WH-11212531-09] Paste the configuration code into "tomcat.service," and start Tomcat. requires: 08
