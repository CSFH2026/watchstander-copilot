1. [step: WH-4517366-01] Open Notepad as an administrator. requires: none
2. [step: WH-4517366-02] Open C:\Windows\System32\drivers\etc. requires: 01
3. [step: WH-4517366-03] Make the hosts file editable. requires: 02
4. [step: WH-4517366-04] Select hosts and click Open. requires: 03
5. [step: WH-4517366-05] Route each Yahoo address you want to block to 127.0.0.1. requires: 04
6. [step: WH-4517366-06] Save the file and restart your PC. requires: 05
