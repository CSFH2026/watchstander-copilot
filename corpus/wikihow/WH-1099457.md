1. [step: WH-1099457-01] Go to http://dashboard.wordpress.com/wp-admin/profile.php and log in if prompted. requires: none
2. [step: WH-1099457-02] Click API Key and other Personal Settings. requires: 01
3. [step: WH-1099457-03] Click get your API key direct from Akismet now. requires: 02
4. [step: WH-1099457-04] Click Set Up Your Akismet Account. requires: 03
5. [step: WH-1099457-05] Choose your plan and create your account. requires: 04
6. [step: WH-1099457-06] Go to your site's dashboard and log in if prompted. requires: 05
7. [step: WH-1099457-07] Click Settings. requires: 06
8. [step: WH-1099457-08] Click Manually enter an API key. requires: 07
9. [step: WH-1099457-09] Copy the API key in your email and paste it into the text field in WordPress. requires: 08
10. [step: WH-1099457-10] Click Connect with API key. requires: 09
