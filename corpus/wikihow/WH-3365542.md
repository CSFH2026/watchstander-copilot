2. [step: WH-3365542-02] Right-click any message in the chat. requires: 01
3. [step: WH-3365542-03] Click Select Messages. requires: 02
4. [step: WH-3365542-04] Click the bubbles next to each message you want to save. requires: 03
5. [step: WH-3365542-05] Click Copy. requires: 04
6. [step: WH-3365542-06] Open a text file or document. requires: 05
7. [step: WH-3365542-07] Right-click the typing area and select Paste. requires: 06
8. [step: WH-3365542-08] Save the file. requires: 07
