1. [step: WH-2167531-01] Download FFmpeg from https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-full.7z. requires: none
2. [step: WH-2167531-02] Extract the file. requires: 01
3. [step: WH-2167531-03] Rename the extracted folder to "FFmpeg.". requires: 02
4. [step: WH-2167531-04] Move the "FFmpeg" folder to the root of your hard drive. requires: 03
5. [step: WH-2167531-05] Right-click the Start menu and select Command prompt (Admin). requires: 04
6. [step: WH-2167531-06] Run this command: setx /m PATH "C:\FFmpeg\bin;%PATH%". requires: 05
