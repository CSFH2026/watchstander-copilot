1. [step: WH-123595-01] Go to the Java Software Development Kit website. requires: none
2. [step: WH-123595-02] Click DOWNLOAD under the "JDK" heading. requires: 01
3. [step: WH-123595-03] Sign in or create a new Oracle account. requires: 02
4. [step: WH-123595-04] Check the "Accept License Agreement" box, then select your operating system's link. requires: 03
5. [step: WH-123595-05] Double-click the downloaded installation file. requires: 04
6. [step: WH-123595-06] Follow the on-screen installation instructions. On Windows and Linux, you must set the JDK path as well. requires: 05
