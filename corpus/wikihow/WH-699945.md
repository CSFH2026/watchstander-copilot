1. [step: WH-699945-01] Download a BitTorrent Client. requires: none
2. [step: WH-699945-02] Open your BitTorrent client and specify a download location in the Settings/Options menu. requires: 01
3. [step: WH-699945-03] Download a Torrent from a Torrent search site. requires: 02
4. [step: WH-699945-04] Open the torrent in your BitTorrent Client and allow the file to finish downloading. requires: 03
5. [step: WH-699945-05] Leave the file and torrent file in their download folder. requires: 04
6. [step: WH-699945-06] Allow your BitTorrent client to continue to run until the file says "Seeding". requires: 05
