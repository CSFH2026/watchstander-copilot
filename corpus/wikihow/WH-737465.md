1. [step: WH-737465-01] Download the latest version of Ubuntu. requires: none
2. [step: WH-737465-02] Open VirtualBox and click New. requires: 01
3. [step: WH-737465-03] Enter a name and select Linux as the type. requires: 02
4. [step: WH-737465-04] Select Ubuntu 64 as the version. requires: 03
5. [step: WH-737465-05] Choose an amount of RAM to allocate. requires: 04
6. [step: WH-737465-06] Click Create a virtual hard disk now. requires: 05
7. [step: WH-737465-07] Double-click the virtual machine and select the Ubuntu ISO. requires: 06
8. [step: WH-737465-08] Click Install Ubuntu. requires: 07
9. [step: WH-737465-09] Click Erase disk and install Ubuntu. requires: 08
