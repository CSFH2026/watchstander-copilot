1. [step: WH-5076358-01] Open Google Chrome. requires: none
2. [step: WH-5076358-02] Go to https://www.google.co.in/inputtools/try. requires: 01
3. [step: WH-5076358-03] Select Hindi from the language menu. requires: 02
4. [step: WH-5076358-04] Select INSCRIPT from the keyboard menu. requires: 03
5. [step: WH-5076358-05] Type using the on-screen keyboard. requires: 04
6. [step: WH-5076358-06] Highlight the text and press CTRL + C. requires: 05
7. [step: WH-5076358-07] Open the app in which you want to add Hindi text. requires: 06
8. [step: WH-5076358-08] Right-click the typing area and select Paste. requires: 07
