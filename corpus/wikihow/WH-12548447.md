1. [step: WH-12548447-01] Each primary key record must be unique. requires: none
2. [step: WH-12548447-02] The values in the primary key can never change. requires: 01
3. [step: WH-12548447-03] No null values can exist in the primary key. requires: 02
4. [step: WH-12548447-04] If you can't select a primary key that meets this criteria, create a surrogate key. requires: 03
