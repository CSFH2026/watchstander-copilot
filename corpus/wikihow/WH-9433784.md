1. [step: WH-9433784-01] Open Steam and click Library. requires: none
2. [step: WH-9433784-02] Right-click Unturned and click Properties. requires: 01
3. [step: WH-9433784-03] Click the Local Files tab and click Browse Local Files. requires: 02
4. [step: WH-9433784-04] Right-click "Unturned.exe" and click Create Shortcut. requires: 03
5. [step: WH-9433784-05] Rename the shortcut. requires: 04
6. [step: WH-9433784-06] Right-click the shortcut and click Properties. requires: 05
7. [step: WH-9433784-07] Put the location next to "Target" in quotation marks. requires: 06
8. [step: WH-9433784-08] Type "-batchmode -nographics" next to location in the "Target" field. requires: 07
9. [step: WH-9433784-09] Add "+secureserver/" in the "Target" field followed by the name of your server. requires: 08
10. [step: WH-9433784-10] Click Apply and close the window. requires: 09
11. [step: WH-9433784-11] Run the shortcut and then close the command prompt when new folders are created. requires: 10
12. [step: WH-9433784-12] Open the Servers folder followed by the folder with your server name. requires: 11
13. [step: WH-9433784-13] Open the "Server" folder and then open the "Command.dat" file in Notepad. requires: 12
14. [step: WH-9433784-14] Type "Name" followed by the name of your server on the first line. requires: 13
15. [step: WH-9433784-15] Type "map" followed by the map you want to play on in your server on the second line. requires: 14
16. [step: WH-9433784-16] Type "port 27015" on the third line. requires: 15
17. [step: WH-9433784-17] Save the command.dat file. requires: 16
18. [step: WH-9433784-18] Run the server shortcut file. requires: 17
19. [step: WH-9433784-19] Connect to your server in Unturned. requires: 18
