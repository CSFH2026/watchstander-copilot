1. [step: WH-9105373-01] Run ncpa.cpl from the Run dialog. requires: none
2. [step: WH-9105373-02] Press Alt + F and select New Incoming Connection. requires: 01
3. [step: WH-9105373-03] Select a user and click Next. requires: 02
4. [step: WH-9105373-04] Select "Through the internet" and click Next. requires: 03
5. [step: WH-9105373-05] Configure your IPV4 properties and click OK. requires: 04
6. [step: WH-9105373-06] Click Allow Access. requires: 05
7. [step: WH-9105373-07] Allow connections through your firewall and router. requires: 06
8. [step: WH-9105373-08] Set up port forwarding. requires: 07
