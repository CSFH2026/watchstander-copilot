1. [step: WH-2470407-01] Get a backwards-compatible "fat" PS3. requires: none
2. [step: WH-2470407-02] Insert the PS2 disk and press the PS button. requires: 01
3. [step: WH-2470407-03] Assign the controller to Slot 1. requires: 02
4. [step: WH-2470407-04] Open the Game menu and select Memory Card Utility. requires: 03
5. [step: WH-2470407-05] Select New Internal Memory Card. requires: 04
6. [step: WH-2470407-06] Select Internal Memory Card (PS2) and assign to Slot 1. requires: 05
7. [step: WH-2470407-07] Open the Settings menu and select Game Settings. requires: 06
8. [step: WH-2470407-08] Change the Upscaler settings to Normal or Full. requires: 07
