1. [step: WH-13162062-01] If you can't search for the server on Discord, it might have been deleted, or it might be set to not appear in search. requires: none
2. [step: WH-13162062-02] If you can see the server in search, it was not deleted. requires: 01
3. [step: WH-13162062-03] Try to join the server if you see it—if you can join, you were kicked. If not, you're probably banned. requires: 02
