1. [step: WH-6637992-01] Open Notepad as an administrator. requires: none
2. [step: WH-6637992-02] Go to File > Open. requires: 01
3. [step: WH-6637992-03] Go to c:\Windows\System32\Drivers\etc. requires: 02
4. [step: WH-6637992-04] Select All Files from the drop-down menu. requires: 03
5. [step: WH-6637992-05] Select the hosts file and click Open. requires: 04
6. [step: WH-6637992-06] Make your changes. requires: 05
7. [step: WH-6637992-07] Click File > Save. requires: 06
