1. [step: WH-6993997-01] Open an image in Photoshop. requires: none
2. [step: WH-6993997-02] Click the colored square below the tools in the toolbar. requires: 01
3. [step: WH-6993997-03] Use the color picker window to pick a primary color. requires: 02
4. [step: WH-6993997-04] Use the brush tool to draw or mark the image. requires: 03
5. [step: WH-6993997-05] Use the eraser tool to erase marks or parts of the image. requires: 04
6. [step: WH-6993997-06] Use the spot healing tool to remove unsightly spots and blemishes. requires: 05
7. [step: WH-6993997-07] Use the red-eye tool and drag over eyes in an image to remove red-eye. requires: 06
8. [step: WH-6993997-08] Use the lasso tool to draw a selection around a shape in an image that you want to copy. requires: 07
9. [step: WH-6993997-09] Click Filter followed by Filter Gallery. Then select a filter. requires: 08
