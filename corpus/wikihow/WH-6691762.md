1. [step: WH-6691762-01] Press Control + Alt + T to open a terminal. requires: none
2. [step: WH-6691762-02] Type "sudo apt update and press" Enter. requires: 01
3. [step: WH-6691762-03] Type "sudo apt upgrade" and press Enter. requires: 02
4. [step: WH-6691762-04] Install wget if you don't already have it. requires: 03
5. [step: WH-6691762-05] Use "wget" to download the latest page from Google. requires: 04
6. [step: WH-6691762-06] Use "sudo dpkg –I" to install the package. requires: 05
