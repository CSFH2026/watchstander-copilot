1. [step: WH-1727677-01] Open the Terminal. requires: none
2. [step: WH-1727677-02] Type "sudo apt install zip" and press Enter to install ZIP. requires: 01
3. [step: WH-1727677-03] Type "cd" followed by the path of the file or folder you want to zip. requires: 02
4. [step: WH-1727677-04] Type "zip zip_filename.zip filename1 filename2 filename3" and press Enter. requires: 03
