1. [step: WH-1217082-01] Select the text or object you want to turn into a hyperlink. requires: none
2. [step: WH-1217082-02] Click the Insert tab. requires: 01
3. [step: WH-1217082-03] Click the Link button in the toolbar. requires: 02
4. [step: WH-1217082-04] Click Existing File or Web Page in the left and enter the URL. requires: 03
5. [step: WH-1217082-05] To link to another file instead of a website, leave the ""Address"" bar blank and select the file instead. requires: 04
6. [step: WH-1217082-06] Click OK. requires: 05
