1. [step: WH-13150065-01] Click the Text tool. requires: none
2. [step: WH-13150065-02] Type some text, making sure that each line of text is in its own text box. requires: 01
3. [step: WH-13150065-03] Click the text box you want to curve. requires: 02
4. [step: WH-13150065-04] Click the Curve tool. requires: 03
5. [step: WH-13150065-05] Drag the slider left to curve the text upward, and right to curve downward. requires: 04
