1. [step: WH-7260791-01] Open the XAMPP Control Panel. requires: none
2. [step: WH-7260791-02] Click Config. requires: 01
3. [step: WH-7260791-03] Select modules and click Save. requires: 02
4. [step: WH-7260791-04] Open File Explorer to C:\xampp. requires: 03
5. [step: WH-7260791-05] Right-click xampp-control.exe and select Create Shortcut. requires: 04
6. [step: WH-7260791-06] Press Windows Key + R. requires: 05
7. [step: WH-7260791-07] Type shell:startup and click OK. requires: 06
8. [step: WH-7260791-08] Drag the shortcut from C:\xampp to the Startup folder. requires: 07
