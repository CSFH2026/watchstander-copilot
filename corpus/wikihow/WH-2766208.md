1. [step: WH-2766208-01] Open File Explorer. requires: none
2. [step: WH-2766208-02] Open the folder that contains the text files. requires: 01
3. [step: WH-2766208-03] Press Shift and right-click in the folder. requires: 02
4. [step: WH-2766208-04] Click Open command window here. requires: 03
5. [step: WH-2766208-05] Type copy *.txt newfile.txt. requires: 04
6. [step: WH-2766208-06] Press Enter. requires: 05
