1. [step: WH-4740-01] Download the latest version of Visual C++ from https://support.microsoft.com/en-us/help/2977003/the-latest-supported-visual-c-downloads. requires: none
2. [step: WH-4740-02] Download the version of WAMP that is best for your system at http://wampserver.aviatechno.net/. requires: 01
3. [step: WH-4740-03] Open the install file and select your language. requires: 02
4. [step: WH-4740-04] Agree to the terms and conditions. requires: 03
5. [step: WH-4740-05] Make sure all the pre requisitions are met before continuing. requires: 04
6. [step: WH-4740-06] Select the root of a disk drive as the install location for WAMP. requires: 05
7. [step: WH-4740-07] Select which components you want to install. requires: 06
8. [step: WH-4740-08] Click Install. requires: 07
9. [step: WH-4740-09] Select the executable file for your default web browser and text editor. requires: 08
10. [step: WH-4740-10] Click Next followed by Finish. requires: 09
11. [step: WH-4740-11] Click the WAMP icon to launch WAMP. requires: 10
12. [step: WH-4740-12] Click the WAMP icon in the taskbar to open the WAMP menu. requires: 11
13. [step: WH-4740-13] Click Restart All Services to restart WAMP. requires: 12
