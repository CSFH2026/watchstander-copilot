1. [step: WH-1664440-01] Import a simple 2D image in Adobe Illustrator or Inkscape. requires: none
2. [step: WH-1664440-02] Use Live Trace or Bitmap Trace to convert the image into a vector graphic. requires: 01
3. [step: WH-1664440-03] Save the vector graphic in SVG format. requires: 02
4. [step: WH-1664440-04] Open Blender 3D. requires: 03
5. [step: WH-1664440-05] Import the SVG file into Blender 3D. requires: 04
6. [step: WH-1664440-06] Select the SVG curves and convert them to a mesh. requires: 05
7. [step: WH-1664440-07] Select the Mesh and switch to Edit Mode. requires: 06
8. [step: WH-1664440-08] Extrude the faces of the mesh. requires: 07
9. [step: WH-1664440-09] Switch back to object mode and apply material properties to the mesh. requires: 08
10. [step: WH-1664440-10] Save your work. requires: 09
