1. [step: WH-3632828-01] Turn on the controller. requires: none
2. [step: WH-3632828-02] Connect the controller to your computer using a USB cable. requires: 01
3. [step: WH-3632828-03] Go https://github.com/nefarius/ScpToolkit/releases/tag/v1.6.238.16010 in a web browser. requires: 02
4. [step: WH-3632828-04] Click the "ScpToolkit_Setup.exe" link to download the install file. requires: 03
5. [step: WH-3632828-05] Install ScpToolkit. requires: 04
6. [step: WH-3632828-06] Open the "ScpToolkit Driver Installer" program. requires: 05
7. [step: WH-3632828-07] Click "Choose DualShock 3 Controllers to Install". requires: 06
8. [step: WH-3632828-08] Check the "Wireless Controller" option. requires: 07
9. [step: WH-3632828-09] Click Install. requires: 08
