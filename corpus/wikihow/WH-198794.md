1. [step: WH-198794-01] Choose someone to be “Simon.”. requires: none
2. [step: WH-198794-02] Have “Simon” give a command to the other players. requires: 01
3. [step: WH-198794-03] If the command starts with “Simon says…” the players have to do it. requires: 02
4. [step: WH-198794-04] If the command doesn’t start with “Simon says…” and a player does it, they’re “out.”. requires: 03
5. [step: WH-198794-05] The last person standing wins! requires: 04
