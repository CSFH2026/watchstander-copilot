1. [step: WH-1607004-01] Start UFW if it's not already running. requires: none
2. [step: WH-1607004-02] Use "sudo ufw allow [port number]" to open a port. requires: 01
3. [step: WH-1607004-03] Use "sudo ufw allow 6000:6007/tcp" to open a range. requires: 02
4. [step: WH-1607004-04] Use "sudo ufw status numbered" to view the rules. requires: 03
