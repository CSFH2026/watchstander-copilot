1. [step: WH-1639835-01] Connect a live internet cable to the internet port on the modem. requires: none
2. [step: WH-1639835-02] Use an ethernet cable to connect the modem to the "WAN" port on a wireless router. requires: 01
3. [step: WH-1639835-03] Use an ethernet cable to connect a computer to the router. requires: 02
4. [step: WH-1639835-04] Enter the router's IP address in a web browser address bar. requires: 03
5. [step: WH-1639835-05] Log in using the router's default username and password. requires: 04
6. [step: WH-1639835-06] Locate the Network name (SSID) and Password settings. requires: 05
7. [step: WH-1639835-07] Create a name and password for your wireless network. requires: 06
8. [step: WH-1639835-08] Save your settings. requires: 07
9. [step: WH-1639835-09] Use the wireless name and password to connect other computers and devices to the network. requires: 08
