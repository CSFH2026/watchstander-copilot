1. [step: WH-675487-01] Download and install Rufus from https://rufus.ie/. requires: none
2. [step: WH-675487-02] Download the ISO file for the operating system you want to install. requires: 01
3. [step: WH-675487-03] Use Rufus to create a USB install disk from the ISO file. requires: 02
4. [step: WH-675487-04] Create a partition for the new operating system in Disk Management. requires: 03
5. [step: WH-675487-05] Disable Fast Boot in the Windows Control Panel. requires: 04
6. [step: WH-675487-06] Boot into the computer BIOS and disable Secure Boot. requires: 05
7. [step: WH-675487-07] Set the Boot order to boot from the USB drive first. requires: 06
8. [step: WH-675487-08] Boot your computer from the USB Install disk. requires: 07
9. [step: WH-675487-09] Select your language and keyboard layout. requires: 08
10. [step: WH-675487-10] Select the "Custom" or "Other" install option while installing the new operating system. requires: 09
11. [step: WH-675487-11] Select the new disk partition and format it. requires: 10
12. [step: WH-675487-12] Follow the instructions to complete the installation. requires: 11
