1. [step: WH-418570-01] Use "open -a appname" to launch an app. requires: none
2. [step: WH-418570-02] Use "open path/to/file -a appname" to open a file with an app. requires: 01
3. [step: WH-418570-03] Add "-g" to keep the file in the background. requires: 02
4. [step: WH-418570-04] Add "-F" to open a fresh copy of the app. requires: 03
5. [step: WH-418570-05] Use "-n" to open multiple instances. requires: 04
