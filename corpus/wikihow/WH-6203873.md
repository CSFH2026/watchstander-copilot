1. [step: WH-6203873-01] Connect the tablet to the same Wi-Fi network as the printer. requires: none
2. [step: WH-6203873-02] Open the Settings menu and tap Connections > More connection settings > Printing. requires: 01
3. [step: WH-6203873-03] Select or install a plugin. requires: 02
4. [step: WH-6203873-04] Tap the plugin. requires: 03
5. [step: WH-6203873-05] Select the printer you want to use. requires: 04
6. [step: WH-6203873-06] Open the file. requires: 05
7. [step: WH-6203873-07] Tap the three-dot menu and select Print. requires: 06
8. [step: WH-6203873-08] Select the printer. requires: 07
9. [step: WH-6203873-09] Tap the print icon. requires: 08
