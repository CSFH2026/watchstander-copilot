1. [step: WH-1512761-01] Open a PowerPoint presentation. requires: none
2. [step: WH-1512761-02] Click File and select Export. requires: 01
3. [step: WH-1512761-03] Save the file as an MP4. requires: 02
4. [step: WH-1512761-04] Open iMovie. requires: 03
5. [step: WH-1512761-05] Click File and select Import Media. requires: 04
6. [step: WH-1512761-06] Select a destination under Import To. requires: 05
7. [step: WH-1512761-07] Select the MP4. requires: 06
8. [step: WH-1512761-08] Click Import Selected. requires: 07
