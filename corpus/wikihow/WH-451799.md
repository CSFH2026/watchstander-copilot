1. [step: WH-451799-01] Create a new path called lib in your project folder. requires: none
2. [step: WH-451799-02] Copy and paste your JARs into the lib folder and refresh. requires: 01
3. [step: WH-451799-03] Select all the JARs in the lib folder. requires: 02
4. [step: WH-451799-04] Right-click the selected JARs in the lib folder. requires: 03
5. [step: WH-451799-05] Select Build Path in the menu. requires: 04
6. [step: WH-451799-06] Click Add to Build Path. requires: 05
