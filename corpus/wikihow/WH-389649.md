1. [step: WH-389649-01] Close Microsoft Word. requires: none
2. [step: WH-389649-02] Set the File Explorer to show hidden files and folders. requires: 01
3. [step: WH-389649-03] Navigate to C:\Users\username\AppData\Roaming\Microsoft\Templates in File Explorer. requires: 02
4. [step: WH-389649-04] Rename the "Normal.dotm" file to Normal.old. requires: 03
5. [step: WH-389649-05] Open the Registry Editor. requires: 04
6. [step: WH-389649-06] Navigate to HKEY_USERS.DEFAULT\Software\Microsoft\Office. requires: 05
7. [step: WH-389649-07] Double-click your version of Word. requires: 06
8. [step: WH-389649-08] Delete the Word key. requires: 07
9. [step: WH-389649-09] Restart Word. requires: 08
