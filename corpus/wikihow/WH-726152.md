1. [step: WH-726152-01] Click File > Create New Torrent…. requires: none
2. [step: WH-726152-02] Select a file or directory. requires: 01
3. [step: WH-726152-03] Choose whether to make the torrent private. requires: 02
4. [step: WH-726152-04] Check the box next to "Start seeding.". requires: 03
5. [step: WH-726152-05] Click Create. requires: 04
6. [step: WH-726152-06] Name and save the .torrent file. requires: 05
7. [step: WH-726152-07] Right-click the torrent and select Copy Magnet URI. requires: 06
8. [step: WH-726152-08] Send or share the link. requires: 07
