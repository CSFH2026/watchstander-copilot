1. [step: WH-11917380-01] Open Adobe Illustrator. requires: none
2. [step: WH-11917380-02] Hover your cursor over File and click New. requires: 01
3. [step: WH-11917380-03] Click More Settings. requires: 02
4. [step: WH-11917380-04] Name the project and make sure the "Width" and "Height" fields are set to 5. requires: 03
5. [step: WH-11917380-05] Enter a value for "Bleed.". requires: 04
6. [step: WH-11917380-06] Click the link icon to the right of the bleed values. requires: 05
7. [step: WH-11917380-07] Click Create Document. requires: 06
