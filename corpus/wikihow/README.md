# wikiHow stand-in dataset

Generated from the Hugging Face dataset `b-mc2/wikihow_lists` by `scripts/import_wikihow.py`.
Each `WH-<pageid>.md` file is one wikiHow step list in the corpus format; do not edit them by hand.
The text is by wikiHow contributors under CC BY-NC-SA 3.0, and each file's `source` links its article.
This is stand-in data for building and testing the copilot. It is not Navy doctrine.
