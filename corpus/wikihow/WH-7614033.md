1. [step: WH-7614033-01] Open the Windows Start menu. requires: none
2. [step: WH-7614033-02] Type CMD . requires: 01
3. [step: WH-7614033-03] Double-click the Command Prompt. requires: 02
4. [step: WH-7614033-04] Type shutdown. requires: 03
5. [step: WH-7614033-05] Type \\ followed by the name of the target computer. requires: 04
6. [step: WH-7614033-06] Type /s to shutdown or /r to restart. requires: 05
7. [step: WH-7614033-07] Type /f. requires: 06
8. [step: WH-7614033-08] Type /c. requires: 07
9. [step: WH-7614033-09] Type a shutdown alert message in quotation marks. requires: 08
10. [step: WH-7614033-10] Type /t. requires: 09
11. [step: WH-7614033-11] Type the number of seconds until the shut down or restart happens. requires: 10
12. [step: WH-7614033-12] Press the Enter key. requires: 11
