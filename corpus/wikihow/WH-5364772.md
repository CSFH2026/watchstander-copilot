1. [step: WH-5364772-01] Open Notepad on Windows or TextEdit on Mac. requires: none
2. [step: WH-5364772-02] Click File. requires: 01
3. [step: WH-5364772-03] Click Open. requires: 02
4. [step: WH-5364772-04] Select "All Files" in the drop-down next to the file name box on Windows. requires: 03
5. [step: WH-5364772-05] Click and HTML file to select it and click Open. requires: 04
6. [step: WH-5364772-06] Use the text editor to edit the HTML tags. requires: 05
7. [step: WH-5364772-07] Click File. requires: 06
8. [step: WH-5364772-08] Click Save. requires: 07
