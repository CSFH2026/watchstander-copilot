1. [step: WH-2637891-01] Register for an account at nexusmods.com. requires: none
2. [step: WH-2637891-02] Create new folders called "Skyrim Mods" and "Steam 2.". requires: 01
3. [step: WH-2637891-03] Open your Steam settings and click Downloads. requires: 02
4. [step: WH-2637891-04] Add the "Steam 2" folder. requires: 03
5. [step: WH-2637891-05] Install Skyrim to the "Steam 2" folder. requires: 04
6. [step: WH-2637891-06] Install Mod Organizer and Skyrim Script Extender. requires: 05
7. [step: WH-2637891-07] Run and configure Mod Organizer. requires: 06
8. [step: WH-2637891-08] Find a mod to install on nexusmods.com. requires: 07
9. [step: WH-2637891-09] Click Download with Manager to download a mod. requires: 08
10. [step: WH-2637891-10] Run Mod Loader and select SKSE to start Skyrim. requires: 09
