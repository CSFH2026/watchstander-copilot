1. [step: WH-1518298-01] Click the location you want to add a marker in the timeline. requires: none
2. [step: WH-1518298-02] Press the "Enter" key. requires: 01
3. [step: WH-1518298-03] Type a name for the marker. requires: 02
4. [step: WH-1518298-04] Select a number for the marker using the drop-down menu at the top. requires: 03
5. [step: WH-1518298-05] Select the "Marker" option below "Time Properties". requires: 04
6. [step: WH-1518298-06] Add any general properties you wish to add. requires: 05
7. [step: WH-1518298-07] Provide a comment, if you want. requires: 06
8. [step: WH-1518298-08] Click Ok. requires: 07
