1. [step: WH-200395-01] Download and install Ti Connect from https://education.ti.com/en/products/computer-software/ti-connect-sw. requires: none
2. [step: WH-200395-02] Download MarageOS from https://www.ticalc.org/archives/files/fileinfo/139/13949.html (TI-84 Plus, TI-84 Plus only). requires: 01
3. [step: WH-200395-03] Download a game you want to install. requires: 02
4. [step: WH-200395-04] Open TI-Connect. requires: 03
5. [step: WH-200395-05] Click TI DeviceExplorer. requires: 04
6. [step: WH-200395-06] Extract the MIRAGEOS.8xk from teh MarageOS.zip file (TI-84 Plus, TI-84 Plus only). requires: 05
7. [step: WH-200395-07] Drag the MIRAGEOS.8xk file to the TI-Connect icon (TI-84 Plus, TI-84 Plus only). requires: 06
8. [step: WH-200395-08] Extract the game zip file. requires: 07
9. [step: WH-200395-09] Open the Readme file and see which file you need to transfer. requires: 08
10. [step: WH-200395-10] Drag and drop the game file listed in the Readme file to the TI-Connect icon. requires: 09
