1. [step: WH-4304976-01] Download and install MInecraft; Java Edition. requires: none
2. [step: WH-4304976-02] Download and install Minecraft Forge version 1.12.2-14.23.5.2838 from https://files.minecraftforge.net. requires: 01
3. [step: WH-4304976-03] Download the Pixelmon mod file from https://reforged.gg/. requires: 02
4. [step: WH-4304976-04] Navigate to your Minecraft game folder at "C:\Users\[username]\AppData\Roaming\.minecraft" on Windows or "~/Library/Application Support/minecraft" on Mac. requires: 03
5. [step: WH-4304976-05] Create a new folder called "mods" with all lowercase letters, if it's not already there. requires: 04
6. [step: WH-4304976-06] Drag the Pixelmon mod file into the Mods folder. requires: 05
7. [step: WH-4304976-07] Open the Minecraft Launcher. requires: 06
8. [step: WH-4304976-08] Click Installations followed by + New. requires: 07
9. [step: WH-4304976-09] Name the Installation "Pixelmon". requires: 08
10. [step: WH-4304976-10] Select "Release 1.12.2-forge1.12.2-14.23.5.2838" below "Version". requires: 09
11. [step: WH-4304976-11] Click Create. requires: 10
12. [step: WH-4304976-12] Select "Pixelmon" in the drop-down menu next to the Play button in the Minecraft Launcher. requires: 11
13. [step: WH-4304976-13] Click Play. requires: 12
