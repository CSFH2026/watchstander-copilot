1. [step: WH-13183302-01] Log in to your Playstation 4. requires: none
2. [step: WH-13183302-02] Select the Settings menu. requires: 01
3. [step: WH-13183302-03] Navigate to Account Management > Account Information > Security > 2-Step Verification. requires: 02
4. [step: WH-13183302-04] Select Text Message or Authenticator app. requires: 03
5. [step: WH-13183302-05] Follow the instructions to set up 2SV via text message or an authenticator app such as Google Authenticator. requires: 04
6. [step: WH-13183302-06] Select Activate. requires: 05
