1. [step: WH-12816283-01] Click the Windows Start menu and type "cmd". requires: none
2. [step: WH-12816283-02] Click the Command Prompt icon to open it. requires: 01
3. [step: WH-12816283-03] Type "cd" followed by a space. requires: 02
4. [step: WH-12816283-04] Type the address of the folder after the space (i.e. "/Users/username/Documents."). requires: 03
5. [step: WH-12816283-05] Press Enter. requires: 04
