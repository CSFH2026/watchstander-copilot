1. [step: WH-4027257-01] Open Digital Color Meter on your Mac. requires: none
2. [step: WH-4027257-02] Move the mouse cursor to the color. requires: 01
3. [step: WH-4027257-03] Press Command + L to lock the cursor. requires: 02
4. [step: WH-4027257-04] Press Shift + Command + C to copy the hex code. requires: 03
5. [step: WH-4027257-05] Paste the hex code into a file. requires: 04
