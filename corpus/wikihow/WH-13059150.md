1. [step: WH-13059150-01] Install MinGW. requires: none
2. [step: WH-13059150-02] Add the compiler path to your system environment variables. requires: 01
3. [step: WH-13059150-03] Open an elevated command prompt window. requires: 02
4. [step: WH-13059150-04] Enter the directory of the C code. requires: 03
5. [step: WH-13059150-05] Type gcc filename.c -o filename.exe and press Enter to compile. requires: 04
6. [step: WH-13059150-06] Run the program by typing its name and pressing Enter. requires: 05
