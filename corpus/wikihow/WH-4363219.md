1. [step: WH-4363219-01] Click the Windows Start menu and type "Regedit". requires: none
2. [step: WH-4363219-02] Click Registry Editor. requires: 01
3. [step: WH-4363219-03] Navigate to "HKEY_LOCAL_KEY" > "SOFTWARE" > "Policies" > "Google" > "Chrome". requires: 02
4. [step: WH-4363219-04] Right-click and add a new DWORD (32 Bit) value in "Chrome. requires: 03
5. [step: WH-4363219-05] Name the new value "IncognitoModeAvailability". requires: 04
6. [step: WH-4363219-06] Open "IncognitoModeAvailability" and change the value to "1". requires: 05
7. [step: WH-4363219-07] Click Apply followed by Ok. requires: 06
8. [step: WH-4363219-08] Restart your computer. requires: 07
