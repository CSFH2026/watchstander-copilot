1. [step: WH-11145755-01] Download and install Java Development Kit from https://www.oracle.com/technetwork/java/javase/downloads/index.html. requires: none
2. [step: WH-11145755-02] Download and install Android Studio from https://developer.android.com/studio. requires: 01
3. [step: WH-11145755-03] Create a new folder on your Windows desktop called "APK". requires: 02
4. [step: WH-11145755-04] Search for apktool.bat on Google and save the file to the APK folder. requires: 03
5. [step: WH-11145755-05] Download apktool.jar from https://ibotpeaches.github.io/Apktool/ and save it to the APK folder. requires: 04
6. [step: WH-11145755-06] Place an apk file in the APK folder. 7 Navigate to the APK folder in the Windows Command prompt. requires: 05
7. [step: WH-11145755-07] Type "apktool if" followed by the apk file name in the command prompt to install the apk framework. requires: 06
8. [step: WH-11145755-08] Type "apktool d" followed by the apk filename to decompile the apk file. requires: 07
9. [step: WH-11145755-09] Edit the files in the newly created folder in the APK folder. requires: 08
10. [step: WH-11145755-10] Type "apktool b" followed by the folder name of the decompiled apk folder to recompile the apk folder. requires: 09
11. [step: WH-11145755-11] Create a new folder on your Windows desktop called "Signapk". requires: 10
12. [step: WH-11145755-12] Copy the newly compiled apk from the "dist" folder in the decompiled apk folder to the newly created "Signapk" folder. requires: 11
13. [step: WH-11145755-13] Download Signapk.zip from https://forum.xda-developers.com/attachment.php?attachmentid=1846095&d=1364661948. requires: 12
14. [step: WH-11145755-14] Extract the contents to the "Signapk folder. requires: 13
15. [step: WH-11145755-15] Navigate to the "Signapk" folder in the Command Prompt and type "java -jar signapk.jar certificate.pem key.pk8 [apkfilename].apk [apkfilename]-signed.apk" in the Command Prompt. requires: 14
