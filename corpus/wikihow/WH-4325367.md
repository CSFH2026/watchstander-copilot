1. [step: WH-4325367-01] Search for Minecraft Bedrock Edition servers online. requires: none
2. [step: WH-4325367-02] Get the server address and port number for the server you want to join. requires: 01
3. [step: WH-4325367-03] Open Minecraft on your mobile device. requires: 02
4. [step: WH-4325367-04] Log in to your Microsoft account, if you haven't already done so. requires: 03
5. [step: WH-4325367-05] Tap Play. requires: 04
6. [step: WH-4325367-06] Tap the Servers tab. requires: 05
7. [step: WH-4325367-07] Tap Add Server. requires: 06
8. [step: WH-4325367-08] Enter the server name at the top. requires: 07
9. [step: WH-4325367-09] Enter the server address in the second bar. requires: 08
10. [step: WH-4325367-10] Enter the port number in the space near the bottom. requires: 09
11. [step: WH-4325367-11] Tap Save. requires: 10
12. [step: WH-4325367-12] Tap the server you added under "More Servers" towards the bottom. requires: 11
