1. [step: WH-5040458-01] Open a terminal window. requires: none
2. [step: WH-5040458-02] Change to the directory with the DEB file. requires: 01
3. [step: WH-5040458-03] Type "sudo dpkg –i filename.deb" and press Enter. requires: 02
4. [step: WH-5040458-04] Enter your password. requires: 03
5. [step: WH-5040458-05] Run "sudo apt-get install -f" to resolve errors. requires: 04
