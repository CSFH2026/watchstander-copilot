1. [step: WH-4461704-01] Double-click the picture you want to use. requires: none
2. [step: WH-4461704-02] Click Edit and select Copy. requires: 01
3. [step: WH-4461704-03] Click the folder you want to change. requires: 02
4. [step: WH-4461704-04] Go to File > Get Info. requires: 03
5. [step: WH-4461704-05] Click the icon you want to change. requires: 04
6. [step: WH-4461704-06] Go to Edit > Paste. requires: 05
