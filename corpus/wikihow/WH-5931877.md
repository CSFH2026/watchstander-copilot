1. [step: WH-5931877-01] Download the installation file for the version of LibreOffice you have. requires: none
2. [step: WH-5931877-02] Run the installer and select "Modify.". requires: 01
3. [step: WH-5931877-03] Select the language you want to install and choose "This feature, and all subfeatures, will be installed on the hard drive.". requires: 02
4. [step: WH-5931877-04] Continue with the installation. requires: 03
5. [step: WH-5931877-05] Restart LibreOffice. requires: 04
6. [step: WH-5931877-06] Click Tools and select Options. requires: 05
7. [step: WH-5931877-07] Double-click Languages and select Languages. requires: 06
8. [step: WH-5931877-08] Select the language and click Apply. requires: 07
9. [step: WH-5931877-09] Click Restart Now. requires: 08
