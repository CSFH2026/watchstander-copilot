1. [step: WH-6434720-01] Go to https://docs.google.com/ and sign in. requires: none
2. [step: WH-6434720-02] Click Gallery template and select a Brochure template. requires: 01
3. [step: WH-6434720-03] Right-click the images and select Replace image. requires: 02
4. [step: WH-6434720-04] Select an image to replace it with and adjust the size if needed. requires: 03
5. [step: WH-6434720-05] Highlight the placeholder text. requires: 04
6. [step: WH-6434720-06] Paste or type your own text to replace it. requires: 05
7. [step: WH-6434720-07] Click File and Print to print the brochure. requires: 06
