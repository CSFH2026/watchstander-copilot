1. [step: WH-958304-01] Open the terminal. requires: none
2. [step: WH-958304-02] Type "Sudo su" and press Enter. requires: 01
3. [step: WH-958304-03] Enter the root password. requires: 02
4. [step: WH-958304-04] Type "sudo updatedb" and press Enter to update the Java database. requires: 03
5. [step: WH-958304-05] Type "locate openjdk" and press Enter to find the Java installation location. requires: 04
6. [step: WH-958304-06] Type "export JAVA_HOME=" followed by the Java installation location in the terminal and press Enter. requires: 05
7. [step: WH-958304-07] Type "echo echo "JAVA_HOME=' " followed by the installation path. requires: 06
8. [step: WH-958304-08] Add ">> /etc/environment" to the end of the line and press Enter. requires: 07
