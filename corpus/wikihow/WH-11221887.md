1. [step: WH-11221887-01] Open a text editor. requires: none
2. [step: WH-11221887-02] Type ″<nav>″. requires: 01
3. [step: WH-11221887-03] Type ″<ul>″ to start the navigation bar links. requires: 02
4. [step: WH-11221887-04] Type page links in ″<a href="EXAMPLE">EXAMPLE</a>″ and within "<li></li>" tags. requires: 03
5. [step: WH-11221887-05] Type "</ul>" to end the navigation bar links. requires: 04
6. [step: WH-11221887-06] Type "</nav>". requires: 05
