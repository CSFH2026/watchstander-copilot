1. [step: WH-3854152-01] Install an ad blocker to block all ads. requires: none
2. [step: WH-3854152-02] To opt out of AdChoices ads on a phone or tablet, install the AppChoices app and select Opt Out from each company. requires: 01
3. [step: WH-3854152-03] To opt out on a computer, go to https://optout.aboutads.info and select which ads to opt out from. requires: 02
