1. [step: WH-11176812-01] Create a primary NTFS partition in Ubuntu. requires: none
2. [step: WH-11176812-02] Download the Windows 10 ISO from Microsoft. requires: 01
3. [step: WH-11176812-03] Install UNetbootin from the Software Center. requires: 02
4. [step: WH-11176812-04] Use UNetbootin to create a bootable USB Windows 10 drive. requires: 03
5. [step: WH-11176812-05] Boot from the USB drive. requires: 04
6. [step: WH-11176812-06] Follow the on-screen instructions to install Windows. requires: 05
7. [step: WH-11176812-07] Connect to the internet and download EasyBCD. requires: 06
8. [step: WH-11176812-08] Use EasyBCD to add Ubuntu to the boot menu. requires: 07
