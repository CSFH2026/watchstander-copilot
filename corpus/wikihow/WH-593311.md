1. [step: WH-593311-01] Type "&nbsp" to add a single space. requires: none
2. [step: WH-593311-02] Type "&ensp" to add 2 spaces. requires: 01
3. [step: WH-593311-03] Type "&emsp" to add 4 spaces. requires: 02
4. [step: WH-593311-04] Use the non-breaking space (nbsp) 4 times to insert a tab. requires: 03
5. [step: WH-593311-05] Use "br" to add a line break. requires: 04
