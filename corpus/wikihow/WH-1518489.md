1. [step: WH-1518489-01] Open or create a new Illustrator document. requires: none
2. [step: WH-1518489-02] Use the text tool to create a text box for each column. requires: 01
3. [step: WH-1518489-03] Click the small box on the right edge of your first text box near the bottom. requires: 02
4. [step: WH-1518489-04] Click the edge of the next text box to connect the two text boxes. requires: 03
5. [step: WH-1518489-05] Add your text to the first text box. requires: 04
