1. [step: WH-2404838-01] Open Notepad. requires: none
2. [step: WH-2404838-02] Type the commands you want to execute in CMD. requires: 01
3. [step: WH-2404838-03] Click File followed by Save as. requires: 02
4. [step: WH-2404838-04] Select All files (*.*) next to "Save as Type". requires: 03
5. [step: WH-2404838-05] Save the file as a ".bat" file. requires: 04
6. [step: WH-2404838-06] Navigate to where you opened the file and open it. requires: 05
