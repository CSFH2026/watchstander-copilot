1. [step: WH-1275342-01] Open an image you want to edit in Photoshop. requires: none
2. [step: WH-1275342-02] Use one of the Lasso Tools, Magic Wand, or Quick Select tool to select the area you want to change. requires: 01
3. [step: WH-1275342-03] Copy and paste the selection you want to change as a new layer. requires: 02
4. [step: WH-1275342-04] Add a "Hue/Saturation" adjustment layer above the layer with the area you want to change. requires: 03
5. [step: WH-1275342-05] Right-click the "Hue/Saturation" layer and click Create Clipping Mask. requires: 04
6. [step: WH-1275342-06] Check "Colorize" in the Hue/Saturation adjustment panel. requires: 05
7. [step: WH-1275342-07] Use the slider bars in the Hue/Saturation adjustment panel to change the color. requires: 06
8. [step: WH-1275342-08] Save the image when you are finished. requires: 07
