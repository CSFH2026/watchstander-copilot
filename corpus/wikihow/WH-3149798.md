1. [step: WH-3149798-01] Install and run Minecraft: Java Edition. requires: none
2. [step: WH-3149798-02] Go to https://files.minecraftforge.net/ in your web browser. requires: 01
3. [step: WH-3149798-03] Click Installer below the recommended download box. requires: 02
4. [step: WH-3149798-04] Wait 6 second and click Skip in the upper-right corner. requires: 03
5. [step: WH-3149798-05] Navigate to the "forge-[version number]-installer.jar" file in your Downloads folder. requires: 04
6. [step: WH-3149798-06] Double-click the "forge-[version number]-installer.jar" file. requires: 05
7. [step: WH-3149798-07] Ensure the "Install Client" option is selected. requires: 06
8. [step: WH-3149798-08] Ensure the Minecraft install folder is correct. requires: 07
9. [step: WH-3149798-09] Click Ok to install Minecraft Forge. requires: 08
10. [step: WH-3149798-10] Click Ok when the installation is complete. requires: 09
