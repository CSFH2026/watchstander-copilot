1. [step: WH-298374-01] Create a subtitle file in Notepad. requires: none
2. [step: WH-298374-02] Save the file with the ".srt" extention. requires: 01
3. [step: WH-298374-03] Change the encoding if the subtitles aren't in English. requires: 02
4. [step: WH-298374-04] Open the video in VLC. requires: 03
5. [step: WH-298374-05] Click the Subtitle tab. requires: 04
6. [step: WH-298374-06] Navigate to Sub Tract > Track 1. requires: 05
7. [step: WH-298374-07] Import your subtitle file. requires: 06
