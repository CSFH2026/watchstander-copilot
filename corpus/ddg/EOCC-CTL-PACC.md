symptoms:
- PACC not responding
- loss of control from CCS
- programmed control lever has no effect
- PACC plasma displays blank
- loss of propulsion control at the PACC
causes:
- PACC console power or processor failure
- data multiplex system fault
- programmed control lever fault
effects:
- no remote control of the GTMs and propeller pitch
- reduced maneuverability until local control is set

1. [step: EOCC-CTL-PACC-01] Verify that the PACC does not control the GTMs or propeller pitch. requires: none
2. [step: EOCC-CTL-PACC-02] Report the casualty to the EOOW, the bridge, and the Chief Engineer. requires: 01
3. [step: EOCC-CTL-PACC-03] Station qualified operators at SCU 1 and SCU 2. requires: 02
4. [step: EOCC-CTL-PACC-04] Set each SCU MODE select switch to LOCKOUT MANUAL, and verify THRUST CONTROL LOCAL LOCKOUT and LOCAL at the PACC. requires: 03
5. [step: EOCC-CTL-PACC-05] Set up communications between the bridge, CCS, and each SCU for engine and pitch orders. requires: 04
6. [step: EOCC-CTL-PACC-06] Answer bridge orders with the SCU manual throttle control levers and the pitch control lever. requires: 05
7. [step: EOCC-CTL-PACC-07] Return control to the PACC only after the fault is corrected and the PACC orders match the SCU settings. requires: 06. danger: a control shift with orders that do not match can change shaft speed or pitch without warning.
